Seeds and data availability
----------------------------
test_cmvsc.py sets global seed 42 and uses it for set_seed, AMV, DataLoader,
and BONE; MVDataset.shuffle() defaults to 42. This applies to its seven active
rows and the commented CCV row if enabled. test_cmvsc_large.py is different:
AMV/DataLoader use 44, it does not call set_seed, BONE seed is omitted (its
constructor default is 1), and shuffle defaults to 42. Therefore a single
YouTubeFace50 default training seed is NOT_FOUND. All data paths resolve from
the current working directory as data/<dataset-id>.mat. CCV.mat and
YouTubeFace50.mat are absent in this checkout. Caltech-5V's dataset_info dims
(40,254,928,512,1984) disagree with the present file's X1..X5 loader order;
the table reports the latter runtime order without changing either source.

Candidate balanced ordered complementary action rule
----------------------------------------------------
V=2: generator sizes {1},     S=2,  |G|=[1,1], |H|=[1,1]
V=3: generator sizes {1,2},   S=6,  |G|=[1,2], |H|=[1,2]
V=4: generator sizes {2},     S=6,  |G|=[2,2], |H|=[2,2]
V=5: generator sizes {2,3},   S=20, |G|=[2,3], |H|=[2,3]
V=6: generator sizes {3},     S=20, |G|=[3,3], |H|=[3,3]

For every enumerated action, G intersect H is empty, G union H is all views,
the action is unique, and its reverse H -> G is present. Ordering is generator
size ascending and then lexicographic generator tuple order. Consequently,
the per-dataset S values are MNIST-USPS=2, BDGP=2, CCV=6, Caltech-5V=20,
HandWrite=20, COIL20=6, MSRC=6, YouTubeFace50=6, and ALOI=6. Maximum S=20
(Caltech-5V and HandWrite); there is no action-count explosion among supported
view counts.

MSRC backward compatibility
---------------------------
The proposed V=4 order is exactly:
(0,1), (0,2), (0,3), (1,2), (1,3), (2,3).
Its complements are exactly:
(2,3), (1,3), (1,2), (0,3), (0,2), (0,1).
The same arrays were read from
outputs/bone_p2/p2_a0_msrc_seed20/p2_a0_carrier_pre_gt.npz.
MSRC_ACTION_ORDER_PARITY = true.
