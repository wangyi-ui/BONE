For each training seed s:

1. train corrupted native BONE carrier
2. construct seed-specific U_cycle^(s)

4. run P2-A0 scientific gate
5. only if P2-A0 passes, run P2-A1 four-arm action pilot

AUC_U_TRUE >= 0.60
Delta_AUC_U >= 0.05
REL_AUC >= 0.60
REL_GAP > 0
