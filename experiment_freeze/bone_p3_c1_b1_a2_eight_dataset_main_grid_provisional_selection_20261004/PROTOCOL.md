# P3-C1-B1-A2 Eight-Dataset Main-Grid Freeze

All eight datasets completed the preregistered 25-candidate
main search grid.

Selection was performed using the frozen lexicographic rule:

1. maximum round(mean_delta_j, 12)
2. maximum round(worst_delta_j, 12)
3. maximum positive_count
4. smaller semantic_exposure
5. smaller semantic_lr

The selected parameters remain provisional until the
preregistered LR-boundary protocol is resolved.

Boundary extension required: True

Lower-boundary hits: NONE
Upper-boundary hits: BDGP

No full GT, ACC, NMI, or ARI was used for parameter selection.
